# 네이버 SA 변경 효과 추적판

광고센터에서 바꾼 것(입찰가·타겟팅·예산·ON/OFF·키워드·소재 등)이 **그 뒤 성과를 어떻게 바꿨는지** 한 화면에서 보여 줍니다.
각자 자기 네이버 검색광고 API 키를 넣으면, 그 키로 관리하는 광고주만 보입니다.

---

## 처음 쓰는 분 (3단계)

> 화면 그림이 있는 자세한 안내는 폴더 안 **`설치가이드.html`** 을 더블클릭해서 보세요.

1. **내려받기** — 이 저장소 페이지에서 초록색 `Code` → `Download ZIP` → 원하는 곳(예: 바탕화면)에 압축 풀기
2. **`setup.bat` 더블클릭**
   - Python 이 없으면 설치 페이지가 열립니다. 설치 첫 화면에서 **"Add python.exe to PATH" 체크** 후 설치하고, `setup.bat` 을 다시 실행하세요.
   - 안내에 따라 **엑세스라이선스 · 비밀키 · CUSTOMER_ID** 입력 (광고센터 → 도구 → API 사용 관리). 입력해도 화면에 안 보이는 게 정상입니다.
   - 관리계정 선택 → 매일 자동 갱신 시각(기본 07:30) → 첫 수집 순서로 진행됩니다.
3. **바탕화면의 `SA 변경 효과` 바로가기**로 결과 화면을 엽니다. 매일 아침 자동으로 새로 만들어집니다.

> 키를 바꾸거나 관리계정을 다시 고르려면 `setup.bat` 을 다시 실행하면 됩니다.
> 지금 바로 새로 수집하고 싶으면 `run_daily.bat` 을 더블클릭하세요.

### 화면 보는 법
- 왼쪽: 광고주 목록 (최근 7일 광고비 순). ▼빨강 = 바꾼 뒤 하락한 건이 있음, ▲초록 = 성장한 건이 있음
- 가운데 그래프: 지표 하나씩(광고비·클릭·전환매출·ROAS). **세로 점선 = 바꾼 날**, 점선을 누르면 무엇을 바꿨고 결과가 어땠는지 나옵니다
- 아래 표: 변경 내역. 위 버튼으로 종류(입찰가·타겟팅 등)를 고를 수 있고, 줄을 누르면 바꾸기 전·후 7일 비교가 나옵니다

### 판정 기준
- 바꾼 날을 빼고 **전 7일 vs 후 7일** 하루 평균 비교
- 전환매출이 있으면 전환매출(구매완료), 없으면 클릭이 ±15% 이상이면 성장/하락, 그 사이는 보합
- 바꾼 지 3일 미만 = 관찰중 · 전에 성과가 없던 대상 = 신규 · 클릭이 너무 적음 = 데이터없음
- 같은 기간 계정 전체 흐름도 함께 계산해, 계정 전체가 같이 움직였으면 표시합니다

### 변경 기록은 어디서 오나요?
| 종류 | 언제부터 보이나 |
|---|---|
| 타겟팅(요일/시간·연령·성별·지역), 광고그룹·키워드·소재 추가 | 설치 당일부터 (과거 35일치 자동으로 채움) |
| 입찰가·예산·ON/OFF·삭제 | 설치 다음 날부터 (매일 전날과 비교해 감지) |
| 그 이전 이력 전부 | 광고센터 → 도구 → 변경 이력 관리 → 다운로드한 엑셀을 `data\inbox\<광고주 로그인ID>\` 폴더에 넣으면 다음 수집 때 반영 |

### 문제가 생기면
`data\run.log` 를 메모장으로 열어 마지막 줄을 보세요.
| 로그 | 뜻 / 할 일 |
|---|---|
| `완료 (…초)` | 정상 |
| `✖ 광고주이름: …` | 그 광고주만 실패 (권한·계정 상태 확인). 나머지는 정상 |
| `API 키가 등록되지 않았습니다` / `403` | `setup.bat` 다시 실행해 키 재등록 |
| 오늘 날짜 기록이 없음 | 자동 실행 시각에 PC가 꺼져 있었음 → `run_daily.bat` 실행 |

로그에는 키가 남지 않으니, 문의할 때 로그를 그대로 보여 줘도 됩니다.

## 보안
- API 키는 **각자 PC에서 Windows 암호화(DPAPI)** 로 저장됩니다 (`data\credentials.bin`). 그 PC의 그 Windows 사용자만 풀 수 있어, 파일이 복사돼도 키를 읽을 수 없습니다.
- 키는 코드·`.env`·로그·결과 화면 어디에도 평문으로 남지 않습니다. 서버로 보내지도 않습니다 (네이버 API 로만 전송).
- `data\`(키·수집 데이터)와 `output\`(광고주 실적 화면)은 저장소에 올라가지 않습니다(`.gitignore`). 커밋 전 키 검사 훅(`.githooks/pre-commit`)도 있습니다: `git config core.hooksPath .githooks`
- 결과 화면은 외부 스크립트·외부 전송이 차단돼 있습니다. 다만 **광고주 실적이 들어 있으니 공유할 때 주의**하세요.
- 키가 유출됐다고 의심되면 광고센터에서 재발급 후 `setup.bat` 으로 다시 등록하세요.

## 설정 (선택)
`.env.example` 을 `.env` 로 복사해 바꿀 수 있습니다. **API 키는 넣지 마세요** (setup.bat 이 암호화해 따로 저장).
비교 기간(`WINDOW_DAYS`), 판정 기준(`THRESHOLD_PCT`), 전환 종류(`CONV_TYPES`), 관리계정(`MANAGER_ACCOUNT_NOS`) 등.

## 명령 (개발·문제 해결용)
```
python main.py run       # 수집 + 엑셀 가져오기 + 화면 생성
python main.py import    # inbox 엑셀만 반영
python main.py build     # 화면만 다시 생성
python main.py accounts  # 불러올 광고주 목록 확인
python main.py demo      # API 없이 예시 화면 (output\demo.html)
python setup_wizard.py   # = setup.bat
```

## 파일
- `data\history.db` 수집한 성과·변경 기록 (지우면 처음부터 다시 수집)
- `data\snapshots\` 매일 계정 구조 스냅샷 (전날과 비교용)
- `data\run.log` 실행 기록
- `output\index.html` 최신 화면, `output\change_impact_YYYY-MM-DD.html` 날짜별 보관본
