네이버 검색광고 · 팀 공용 도구

SA 변경 효과 설치 가이드

광고센터에서 바꾼 것(입찰가·타겟팅·예산·키워드 등)이 그 뒤 성과를 어떻게 바꿨는지 매일 아침 자동으로 정리해 주는 도구입니다. 내 API 키를 한 번 넣으면, 내가 관리하는 광고주만 보입니다.

설치 10분첫 수집 광고주 70개 기준 약 30분Windows 10 · 11

준비물

  • 프로그램 ZIP 파일 (SA_change_tracker_v1.zip). 담당자에게 받거나 GitHub 저장소에서 Code → Download ZIP
  • 내 네이버 검색광고 API 키 3개. 광고센터 → 도구 → API 사용 관리에서 확인합니다. 처음이면 네이버 검색광고 API 서비스 신청을 누르면 바로 발급됩니다.

API 키는 비밀번호와 같습니다. 메신저·메일·채팅에 붙여 넣지 말고, 설치 화면에만 직접 입력하세요.

1압축 풀기

ZIP 파일을 오른쪽 클릭 → 압축 풀기(모두 압축 풀기). 바탕화면이나 문서 폴더처럼 찾기 쉬운 곳에 풉니다.

풀린 SA_change_tracker 폴더 안에 setup.bat이 있으면 준비 완료입니다.

ZIP을 더블클릭해서 압축을 풀지 않은 채 안에서 실행하면 설치가 되지 않습니다. 꼭 먼저 풀어 주세요.

2setup.bat 더블클릭

검은 창이 열리고 설치 안내가 시작됩니다.

이런 창이 먼저 뜨면

  • "Windows의 PC 보호" / "게시자를 확인할 수 없습니다": 추가 정보 → 실행 또는 실행을 누르세요. 인터넷에서 받은 파일이라 뜨는 기본 경고입니다.
  • "Python 이 설치돼 있지 않습니다": 함께 열리는 Python 다운로드 페이지에서 설치합니다. 설치 첫 화면 아래쪽 Add python.exe to PATH를 꼭 체크하고 Install Now. 설치가 끝나면 setup.bat을 다시 실행합니다.

3API 키 입력

세 값을 차례로 입력하고 각각 Enter를 누릅니다.

  • 복사한 키는 Ctrl+V 또는 마우스 오른쪽 클릭으로 붙여 넣습니다.
  • 엑세스라이선스와 비밀키는 입력해도 화면에 아무것도 안 보입니다. 정상입니다. 한 번만 붙여 넣고 Enter를 누르세요.
  • 입력이 끝나면 네이버에 바로 확인해서 ✔ 키 확인 완료가 나옵니다.
  • 틀리면 이유가 나오고 다시 입력할 수 있습니다(3번까지).

키는 이 PC의 내 Windows 계정에서만 열리게 암호화돼 저장됩니다. 폴더가 복사돼도 다른 사람은 읽을 수 없습니다.

 setup.bat

"✖ 키 확인 실패"가 나오면

  • 세 값이 같은 계정에서 나온 것인지 확인하세요. 다른 사람 계정의 CUSTOMER_ID를 넣으면 실패합니다.
  • 키 앞뒤에 공백이나 줄바꿈이 같이 복사되지 않았는지 확인하세요.
  • 광고센터에서 키를 방금 재발급했다면 새 키를 넣으세요. 예전 키는 쓸 수 없습니다.

4내 광고주 고르기

내 아이디에 연결된 관리계정 목록이 나옵니다.

  • 그냥 Enter를 누르면 내가 책임자(OWNER)인 관리계정이 선택됩니다. 대부분 이걸로 충분합니다.
  • 다른 관리계정도 보고 싶으면 번호를 쉼표로 입력합니다. 예: 2,4
  • 담당자 이름은 결과 화면 위쪽에 표시됩니다. 비워도 됩니다.

마지막 줄에 불러올 광고주 수가 나오면 맞게 고른 겁니다. 0개면 setup.bat을 다시 실행해 번호를 바꾸세요.

5자동 갱신과 첫 수집

  • 자동 갱신: Enter 두 번이면 매일 07:30에 자동 수집하도록 등록됩니다. 그 시간에 PC가 꺼져 있었으면 켜진 뒤 바로 수집합니다.
  • 첫 수집: Enter를 누르면 지난 35일치 성과를 받아옵니다. 광고주가 많으면 30분 넘게 걸리니 창을 닫지 말고 기다리세요.
  • 끝나면 결과 화면이 열리고, 바탕화면에 SA 변경 효과 바로가기가 생깁니다.

자주 묻는 질문 · 문제 해결

상황할 일
오늘 화면이 갱신되지 않았어요폴더 안 data\run.log를 메모장으로 열어 마지막 줄을 확인하세요. 오늘 날짜가 없으면 run_daily.bat을 더블클릭해 바로 수집합니다.
로그에 ✖ 광고주이름이 있어요그 광고주만 실패한 것이고 나머지는 정상입니다. 해당 광고주 권한이나 계정 상태를 확인하세요.
로그에 403 또는 키가 등록되지 않았습니다키가 바뀌었거나 만료된 것입니다. setup.bat을 다시 실행해 새 키를 넣으세요.
입찰가 변경이 안 보여요입찰가·예산·ON/OFF는 설치 다음 날부터 매일 전날과 비교해 잡힙니다. 그 전 이력이 필요하면 광고센터 도구 → 변경 이력 관리에서 엑셀을 받아 data\inbox\광고주로그인ID\에 넣으세요. 다음 수집 때 반영됩니다.
'변경자 미확인'이 많아요네이버 API는 누가 바꿨는지 알려주지 않습니다. 광고센터 도구 → 변경 이력 관리 엑셀을 data\inbox\광고주로그인ID\에 넣으면 변경자가 채워지고, 내 아이디로 바꾼 건 '나', 다른 아이디는 '다른 사람'으로 나뉩니다.
PC를 바꿨어요키는 PC마다 따로 암호화됩니다. 새 PC에서 ZIP을 풀고 setup.bat을 다시 실행하세요.
키나 관리계정을 바꾸고 싶어요setup.bat을 다시 실행하면 됩니다. 수집한 데이터는 그대로 남습니다.

꼭 지켜 주세요

  • API 키는 설치 화면에만 입력하세요. 메신저·메일·문서·AI 채팅에 붙여 넣지 마세요.
  • 결과 화면(output\index.html)에는 광고주 실적이 들어 있습니다. 회사 밖으로 공유하지 마세요.
  • data 폴더는 다른 사람에게 보내지 마세요. 키는 암호화돼 있지만 수집 데이터가 들어 있습니다.
  • 키가 새어 나갔다고 의심되면 광고센터에서 재발급하고 setup.bat으로 다시 등록하세요.
로그를 공유해도 키는 남지 않습니다. 막히는 곳이 있으면 data\run.log 마지막 줄과 함께 문의하세요.
